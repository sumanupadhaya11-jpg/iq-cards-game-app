# IQ CARD'S GAME - Android App with AdMob

Complete production-ready React app for IQ CARD'S GAME with integrated AdMob ads.

## Files in this Project:

1. App.jsx - Main React component with AdMob integration
2. main.jsx - React entry point
3. index.html - HTML template
4. package.json - Dependencies and scripts
5. capacitor.config.json - Capacitor & AdMob configuration
6. vite.config.js - Build configuration
7. .gitignore - Git ignore rules

## Features:

Base44 game embedded (https://iq-card-game.base44.app)
Banner Ad (Bottom of game - Always visible)
Rewarded Ad (For hints)
Interstitial Ad (After game over)
Capacitor ready for Android APK
Production-ready code
